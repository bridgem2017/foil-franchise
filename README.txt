업로드 방법
1. 압축을 풉니다.
2. 모든 파일과 images 폴더를 GitHub 저장소 루트에 그대로 업로드합니다.
3. GitHub Pages를 활성화합니다.
4. index.html 안의 _next 주소를 실제 GitHub Pages 주소로 바꿉니다.

반드시 수정할 곳
- index.html 의 _next 값
예시:
https://username.github.io/repository-name/thanks.html
